# Server (V2)

This folder is scaffolded but intentionally empty until V2.
MVP runs entirely from /client as a static site.

Planned entrypoint: server/index.js (Express app)
- routes/       route definitions (e.g. /api/profiles, /api/contact)
- controllers/  request handlers
- middleware/   auth, validation, error handling
- database/     connection + migrations (MySQL)
- models/       data access layer
